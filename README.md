# Manchester United Premier League Performance Analysis

**Ten games of signal and noise: what Manchester United's 18th place really means.**

AMA2233 Data Analytics and Visualization · course project · data extracted 18 November 2026.

## What this project claims

1. **The decline is real** — over identical windows (the first ten rounds), United went from 17 points (6th) in 2025/26 to 8 points (18th) in 2026/27.
2. **The table overstates it** — a Poisson expected-points model (xPts) rates United's ten games at 13.0 points: the 12th-best team, not the 18th, with the league's third-worst luck deficit (−5.0).
3. **Ten-game tables are weak evidence** — across 100 team-seasons (2021/22–2025/26), position after ten rounds correlates ρ = 0.81 with final position; three clubs with identical 17-point starts finished 3rd, 10th and 17th.

## Reproduction

Requirements: Python 3.10+, pandas, numpy, matplotlib; python-docx and python-pptx for the document builders.

```bash
python analysis_pipeline.py          # regenerates processed data + all six figures
python build_report.py               # rebuilds report/Academic_Report.docx
python build_deck.py                 # rebuilds presentation/Presentation.pptx
```

The notebook is generated from `analysis_pipeline.py` and can be run with "Restart and run all" from the project root.

## Limits

The 2026/27 season is partial (100 matches through 8 November 2026). xG exists only in the
current-season file, so the chance decomposition is within-season. The xPts model assumes
independent Poisson scorelines. No player-level, injury or tactical data are used; mechanisms
are hypotheses consistent with the aggregates. No causal claims are made.
